LOOPS MARKS PRO — V4

1. EXTRAIA o ZIP e faça upload de todos os arquivos da raiz para GitHub.
2. No Netlify, importe este repositório GitHub (não use Netlify Drop nesta versão).
3. Build: npm run build | Publish: dist | Functions: netlify/functions | Base: vazio.
4. Ative Identity no Netlify, altere o registro para Invite only e convide seu e-mail.
5. Faça login no site, cadastre música, suba WAV, espere Sincronizado.
6. No celular, use Gerar link → Modo Live, login com a mesma conta, Baixar para offline.
7. Em Backup / Restaurar, exporte primeiro um backup completo em ZIP.

DADOS GUARDADOS: Netlify Blobs (loops-v3-songs, loops-v3-wavs, loops-v3-history).
SEM SUPABASE. Armazenamento offline: IndexedDB do celular, não uma pasta visível.

AVISO: A geração do pacote foi validada por testes locais, mas o build com bibliotecas
externas, a autenticação real e a execução no Netlify/iPhone ainda exigem testes.
Veja o README.md para detalhes, limites de áudio e backup.
