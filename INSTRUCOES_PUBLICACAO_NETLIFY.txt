LOOPS MARKS PRO V8 — INSTALAÇÃO NO MESMO NETLIFY

1. Guarde a V6 em ZIP e faça backup de todas as músicas no aplicativo, se possível.
2. Extraia este ZIP; envie os ARQUIVOS extraídos para a raiz do GitHub LoopsMarksPro.
3. Netlify: Base directory vazio; Build command npm run build; Publish directory dist;
   Functions directory netlify/functions. Identity deve estar ativado com Invite only.
4. Para receber links de convite ou recuperação, publique a V8 no endereço PRINCIPAL
   (um deploy já concluído pode ser promovido, sem novo build).
5. Confirme V8 no navegador InPrivate antes de pedir um novo e-mail.
6. Se o Netlify disser excesso de tentativas, não repita o pedido: é bloqueio
   do Identity. Aguarde a liberação e use apenas o link mais recente.
7. Primeiro faça login, confirme a Central e salve uma música pequena. Teste
   também /.netlify/functions/loops-session (sem login retorna 401).
8. Mantenha a V6 guardada; nenhum outro projeto ou variável LOOPS_ADMIN_* é necessário.

A V8 usa os mesmos stores Netlify Blobs e o mesmo IndexedDB da V6.
TESTES LOCAIS não substituem validação real do Identity, nuvem e WAV offline.
